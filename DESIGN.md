# Health Check interface

## Product direction

A practical checking tool with a text editor and report. The user selected the recommended GitHub/Linear-like working-app direction after rejecting the promotional layout. The interface uses familiar controls and compact spacing.

## Structure

A small header holds the product name, AI connection and installation controls. A tab row opens Checker, AI review, Sources and Guide. Each screen has a short title and one line of context. There is no marketing hero, slogan, promotional card grid or authority-logo strip.

On desktop, the checker has two panes: the editable claim and the report. Long reports scroll in their own pane while the claim remains visible. On phones, the report follows the editor in the page's normal scroll flow. An empty report describes its method and coverage. Editing previously checked text makes the report require a new check.

## Visual system

White canvas, neutral gray panel headers and thin borders. Charcoal marks the primary action and selected tab. Blue links identify references. Semantic warning colors are limited to the report and feedback. The shield geometry remains the brand mark, with monochrome installation icons.

One system sans family. Screen titles are 22–24px; ordinary interface text is 14–16px and editable text is 16px. Supporting text stays legible. No decorative animation, oversized typography, serif accent, pill navigation or artificial statistics.

Mouse, keyboard and touch work through the same controls. Ctrl/Cmd+Enter checks the claim. Focus is visible. Changed, empty, offline, disconnected and error states name the next action.

## Content and delivery

Preserve the existing curated health claims, source registry and API boundaries. Local checks do not establish truth. The AI assistant has no live web search. Never cache chat requests or responses.
