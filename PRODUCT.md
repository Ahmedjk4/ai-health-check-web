# Health Check

Health Check helps people inspect health claims copied from social posts, forwarded messages, or AI answers. Its main action is to paste text and run a local English-language warning-sign check.

It is a responsive website and installable PWA. The existing Node server, offline pattern engine, source registry, and optional Hack Club AI chatbot remain the foundation. API credentials stay on the server. There is no account or conversation database.

The local checker detects patterns and known myths; it cannot establish truth. The assistant has no live web browsing. Important health decisions require current evidence and qualified clinical advice.

Support readable text, keyboard navigation, touch targets, small phones, computers, offline checking and clear error states. Preserve the original source projects and private server configuration.
